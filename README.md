# 課題・締め切り管理アプリ

学生が授業課題、レポート、テスト勉強、提出物の締め切りを管理するためのWebアプリケーションです。

最初は最小構成で制作し、その後にSupabase連携、ログイン、通知、カレンダーなどの機能を段階的に追加します。

## 対象ユーザ

- 学生

## 主な利用場面

- 授業課題の管理
- レポートの締め切り管理
- テスト勉強の予定管理
- 提出物の締め切り管理

## 画面構成

- ログイン画面
- ダッシュボード
- 課題一覧画面
- 課題登録・編集画面
- 分類管理画面
- 管理画面

## 機能要件

- ユーザー登録・ログイン機能
- 課題の作成、編集、削除
- 課題名、締切日、優先度、完了状態、メモ欄の登録
- 科目ごとの分類
- レポート、テスト、提出物などの種類分類
- 利用者が自由に作れるカスタムグループ
- グループ数の上限設定
- 締切が近い順、優先度順、未完了のみなどの並べ替え・絞り込み
- 完了済み課題の表示・非表示切り替え
- 今日締切、明日締切、今週締切などの表示
- 課題の検索機能
- 繰り返し課題への対応
- 課題へのファイルやURLの添付
- カレンダー表示
- ダッシュボード表示

## 通知設定

- 締切前日の通知
- 当日の通知
- 任意のタイミングで通知設定
- メール通知
- Web Push通知
- 通知を受け取る・受け取らない設定
- 完了済み課題には通知しない処理

## 技術要件

| 項目 | 技術 |
| --- | --- |
| フロントエンド | Next.js |
| 言語 | TypeScript |
| UI | Tailwind CSS + shadcn/ui |
| バックエンド | Supabase |
| データベース | PostgreSQL |
| 認証 | Supabase Auth |
| ホスティング | Vercel |
| バージョン管理 | GitHub |
| 通知 | 最初はアプリ内通知、後でメール/Web Push |

## 開発の流れ

1. ローカルだけで課題管理
2. Supabaseに保存
3. ログイン対応
4. 通知・カレンダーなどを追加

最小構成で制作したのち、段階的に機能を増やしていきます。

## ローカルでの起動

```bash
npm install
npm run dev
```

起動後、以下のURLで確認します。

```text
http://127.0.0.1:3000
```

## 機能の最小構成

最初に制作する機能は以下の範囲にします。

- 課題登録
- 締切日
- 優先度
- 完了チェック
- 分類
- 並び替え
- 検索
- localStorage保存
- 通知の簡易表示

### 最小構成で扱う分類

最初は分類を複雑にしすぎず、以下の2種類のみを扱います。

- 科目
- 種類

種類は以下の固定項目から選択します。

- レポート
- テスト
- 提出物
- その他

### 最小構成で扱う通知

最初はメール通知やWeb Push通知は実装せず、画面上の表示のみで対応します。

- 締切が近い課題を画面上で強調表示する
- 今日締切の課題を表示する
- 明日締切の課題を表示する

## 現在の実装範囲

- Next.js + TypeScriptで画面を実装
- Tailwind CSSでUIを作成
- 課題の登録、編集、削除
- 締切日、優先度、完了状態、メモ欄の管理
- 科目と種類による分類
- 締切順、優先度順、登録順の並び替え
- 未完了、完了済み、全件の絞り込み
- 科目、種類による絞り込み
- 課題名、科目、メモの検索
- localStorageへの保存
- 今日締切、明日締切、期限切れの画面表示
